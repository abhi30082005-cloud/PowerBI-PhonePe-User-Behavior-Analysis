# 📱 PhonePe Transaction & User Analytics Dashboard

An interactive Power BI dashboard built to analyze transaction trends, user demographics, service category distributions, and platform success metrics for digital payments.

---

## 📊 Key Dashboard Insights & Highlights
* **Aggregate Transaction Value:** ₹528.97M (Total transactions reaching 101K with a robust **96.15% success rate**).
* **Service Distribution:** Money Transfers and Recharge Bills capture the lion's share of the total transaction value, heavily outperforming Loans and Insurance services.
* **Temporal Patterns:** Transaction activity is heavily skewed toward **weekdays (71.49%)** compared to weekends (28.51%).
* **Demographics:** Gen-X (37.4%) and Millennials (37.3%) form the core user base contributing to transaction volumes.
